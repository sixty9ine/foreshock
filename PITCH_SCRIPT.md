## 0:20–0:50 — What you're building

> Foreshock is a risk-scoring API for Solana tokens. You give it a mint address and it scores where that token sits across five stages of the pump-and-collapse lifecycle — attention ignition, float concentration, liquidity trap, insider distribution, exhaustion — with the on-chain evidence behind every number, not just a verdict. It ships as an open API first, because the risk read needs to reach someone at the moment they're about to buy, inside the wallet or the trading screen — not sitting on a dashboard they'd have to think to go check.

## 0:50–1:30 — Why you're the one to build it

> I'd actually been doing this by hand already. Deep-diving AI-agent narrative tokens that collapsed — BICO, HEI, DEXE, TUT — I kept finding the same structural arc every time: ignition, concentration, a squeeze, insiders distributing, then the correction. Reconstructing that sequence manually, after the fact, taught me two things — that the pattern was repeatable, and that nobody was reading it *before* the collapse, only after. That framework predates this hackathon. What I built this weekend is the Solana implementation — all the code here is new, the method isn't, and I've been upfront about that distinction throughout.

## 1:30–2:00 — Close

> It's MIT licensed and live right now — the API, the scorer, the whole thing is open. I'd rather this be infrastructure other products build on than a dashboard I'm trying to keep people on. That's genuinely the whole pitch: a repeatable pattern, read early, handed to whoever's building the thing the buyer's actually looking at.
